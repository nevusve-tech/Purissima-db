# Purissima Cloud

Aplicación interna de Purissima: checklist diario de motos, cierre de caja y gestión de usuarios por PIN.

| Carpeta | Contenido | Se publica en |
|---|---|---|
| `frontend/` | React + Vite + Tailwind | Cloudflare Pages |
| `backend/` | API Express (Node) | Render |
| `database/` | Esquema SQL (PostgreSQL) | Supabase |

Las variables necesarias están en `backend/.env.example` y `frontend/.env.example`.
Nunca subas archivos `.env` con valores reales.
